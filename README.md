# Super Collective Homebrew tap

Mac apps from [Super Collective](https://supercollective.studio).

```sh
brew install --cask supercollective-studio/tap/ratelimitbar
```

| Cask | App |
| --- | --- |
| `ratelimitbar` | [RateLimitBar](https://ratelimitbar.com): Claude Code and OpenAI Codex plan limits in your Mac menu bar |
